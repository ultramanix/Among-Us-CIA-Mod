# CIA — Among Us Mod

CIA is an Among Us role mod built with C#, BepInEx, Reactor and MiraAPI.

## First milestone
- CIA role framework
- KILLER, ALERTER and CENSORER role definitions
- Round-start role reveal panel
- X closes the panel
- Vanilla-style role reveal sound where supported

## Roles
- KILLER
- ALERTER
- CENSORER

This repository is an early development build. APIs are kept behind the current Reactor/MiraAPI versions rather than inventing game internals.
